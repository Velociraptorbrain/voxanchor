# VoxAnchor User Manual

Welcome to VoxAnchor! This is the official user manual.

## Installation
1. Download the installer.
2. Run the installer.
3. Open your DAW and scan for new plugins.

## How to Use
- Turn the Time Tightness knob to align vocals.
- Turn the Pitch Tightness knob to match pitch.
- Use the Ignore and Bypass tools to leave certain areas untouched.
